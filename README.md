# PostgreSQL Navigator

Локальное приложение Streamlit для исследования метаданных PostgreSQL из Excel. В каталоге можно искать таблицы и поля. В разделе «Связи таблиц» можно вручную выбрать от 2 до 10 таблиц и изучить доступные варианты JOIN, их точные условия и промежуточные таблицы. Граф можно масштабировать и перемещать.

AI-поиск принимает вопросы на русском. Локальная Ollama уточняет запрос и выбирает кандидатов, а Navigator сверяет названия таблиц и полей с каталогом. Выбор таблиц в ответе можно скорректировать вручную. Для исходного запроса доступен JSON-отчёт с диагностикой.

Navigator использует экспорт метаданных и показывает условия JOIN. Приложение не подключается к PostgreSQL и не генерирует исполняемый SQL. Бизнес-смысл маршрута и кратность связей требуют отдельной проверки.

## Запуск

Требуется Python 3.11 или новее. Для AI-поиска установите и запустите Ollama с локальной моделью. Каталог и ручной поиск связей работают без модели.

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
ollama pull qwen2.5:7b
.venv\Scripts\python.exe -m streamlit run app.py
```

Откройте http://127.0.0.1:8501. На Windows после установки окружения можно запускать приложение через `Navigator.vbs`. Адрес Ollama, модель и проверка соединения доступны в разделе «Настройки».

## Каталог

В репозитории есть вымышленные метаданные для клиентов, заказов и позиций. В разделе «Связи таблиц» выберите `demo.customers` и `demo.order_items`, чтобы увидеть путь через `demo.orders`.

Для своего каталога замените демонстрационную пару Excel в локальной папке `data/`. В имени первого файла должно быть слово «первый», второго — «второй».

| Файл | Обязательные столбцы |
| --- | --- |
| Поля | `table_schema`, `table_name`, `column_name`, `data_type`, `is_nullable` |
| Связи | `child_schema`, `child_table`, `child_column`, `parent_schema`, `parent_table`, `parent_column` |

Переключатель источников в настройках управляет включением схемы `integration_1c` в AI-поиск. Диагностика сохраняется локально в `diagnostics/` и может содержать исходный вопрос и метаданные. Рабочие каталоги и отчёты храните вне публичного репозитория.
