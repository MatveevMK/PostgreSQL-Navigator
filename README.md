# PostgreSQL Navigator

Локальный помощник для исследования структуры PostgreSQL. Описывайте задачу по-русски: Ollama помогает выбрать таблицы и поля, а приложение проверяет их по Excel и показывает альтернативные пути JOIN через Graphviz.

Приложение не подключается к PostgreSQL и не генерирует исполняемые SQL-запросы. Найденные связи подтверждаются каталогом, но их бизнес-смысл требует проверки пользователем.

## Запуск

Требуются Python 3.10+, установленная Ollama и локальная модель `qwen2.5:7b`.

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
ollama pull qwen2.5:7b
.venv\Scripts\python.exe make_demo.py
.venv\Scripts\python.exe -m streamlit run app.py
```

После установки окружения в Windows можно запускать `Navigator.vbs` двойным щелчком.

`make_demo.py` создаёт вымышленный каталог клиентов, заказов и позиций. Рабочие Excel, журналы и диагностические отчёты в репозиторий не включены.

Для собственного каталога замените демонстрационные Excel в `data`. Файл с «первый» в имени должен содержать `table_schema, table_name, column_name, data_type, is_nullable`. Файл с «второй» — `child_schema, child_table, child_column, parent_schema, parent_table, parent_column`. В папке должна быть одна пара файлов.

## Возможности

- AI-поиск таблиц и полей, ручная корректировка выбора.
- Несколько схем соединения и точные условия JOIN.
- Просмотр каталога и ручной поиск путей.
- JSON-диагностика запросов и ошибок.

Адрес Ollama ограничен локальным компьютером. Диагностика содержит вопросы и метаданные: храните её локально. При отсутствии связи в Excel приложение не должно придумывать её. Понимание бизнес-терминов моделью может быть неточным.
